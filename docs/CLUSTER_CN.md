# Redis 集群支持

picordm 支持 Redis 集群模式，允许您连接和管理 Redis 集群。

## 快速开始

### 创建连接

**方法 1：手动输入**

1. 在连接列表中按 `n` 创建新连接
2. 按 `Tab` 切换到 **集群** 模式
3. 输入集群节点地址（逗号分隔）
   ```
   127.0.0.1:6379, 127.0.0.1:6380, 127.0.0.1:6381
   ```
4. 按 `Ctrl+S` 保存

**方法 2：从剪贴板快速导入**

1. 复制集群连接字符串到剪贴板：
   ```
   redis://127.0.0.1:6379,127.0.0.1:6380,127.0.0.1:6381
   ```
2. 在连接列表中按 `i`
3. 连接会自动创建，名称为 `127.0.0.1-cluster`

支持的格式：

- `redis://host1:port1,host2:port2,host3:port3` - 多个节点（推荐）
- `rediss://user:pass@host1:port1,host2:port2,host3:port3` - 带认证
- `redis-cli -c -h host -p port` - 单个入口点（自动发现其他节点）

### 表单控制

| 按键     | 功能              |
| -------- | ----------------- |
| `↑/↓`    | 导航字段          |
| `Tab`    | 切换单机/集群模式 |
| `Ctrl+S` | 保存连接          |
| `Esc`    | 取消              |

## 功能特性

### 已支持

- ✅ 自动处理集群重定向
- ✅ 查看和管理键
- ✅ 执行 Redis 命令
- ✅ 数据导入/导出
- ✅ TTL 管理
- ✅ 所有数据类型（String、List、Set、ZSet、Hash）

### 限制

- ❌ 不支持 SELECT 命令（自动忽略）
- ❌ 仅支持 db0
