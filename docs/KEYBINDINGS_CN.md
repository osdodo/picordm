# 快速参考 - 按键绑定

## 全局快捷键
| 按键 | 功能 |
|------|------|
| `Ctrl+q` | 退出应用 |

## 功能特性
- ✅ Vim 风格编辑（Normal/Insert/Visual 模式）
- ✅ JSON 语法高亮（自动检测）
- ✅ Vim 命令支持（:w, :q, :wq, :q!）
- ✅ 复制粘贴（系统剪贴板）
- ✅ 撤销/重做
- ✅ 鼠标支持

## Dashboard 模式
| 按键 | 功能 |
|------|------|
| `↑↓` | 选择 key |
| `Enter` | 打开选中的 key |
| `Space` | 选择/取消选择 key |
| `Ctrl+a` | 全选 |
| `/` | 搜索 keys |
| `>` | 进入命令模式 |
| `Ctrl+n` | 切换数据库 |
| `F5` | 刷新 |
| `Ctrl+e` | 导出 |
| `Ctrl+l` | 导入 |
| `Ctrl+t` | 切换连接 |
| `Ctrl+b` | 断开连接 |
| `Delete` | 删除选中的 keys |

## KeyContent 模式（Vim 风格）

### Normal 模式（默认）
| 按键 | 功能 |
|------|------|
| `hjkl` | 左下上右移动 |
| `w` / `e` / `b` | 单词导航 |
| `0` / `$` | 行首/行尾 |
| `gg` / `G` | 文件开头/结尾 |
| `Ctrl+d` / `Ctrl+u` | 半页下/上 |
| `i` | 进入 Insert 模式 |
| `a` | 在光标后进入 Insert |
| `A` | 在行尾进入 Insert |
| `o` / `O` | 新建行并进入 Insert |
| `v` | 进入 Visual 模式 |
| `x` | 删除字符 |
| `dd` | 删除行 |
| `yy` | 复制行 |
| `p` | 粘贴 |
| `u` | 撤销 |
| `Ctrl+r` | 重做 |
| `Ctrl+d` | 半页下跳 |
| `Ctrl+u` | 半页上跳 |
| `ciw` | 修改单词 |
| `:w` | 保存到 Redis（Vim 风格） |
| `:q` | 返回 Dashboard |
| `:wq` / `:x` | 保存并返回 |
| `:q!` | 强制退出不保存 |
| `Ctrl+s` | 保存（兼容） |

### Insert 模式
| 按键 | 功能 |
|------|------|
| 字符输入 | 正常输入 |
| `Enter` | 换行 |
| `Backspace` | 删除前一个字符 |
| `Esc` | 返回 Normal 模式 |

### Visual 模式
| 按键 | 功能 |
|------|------|
| `hjkl` | 扩展选择 |
| `y` | 复制 |
| `d` | 删除 |
| `Esc` | 返回 Normal 模式 |

## 命令模式
| 按键 | 功能 |
|------|------|
| 输入命令 | 输入 Redis 命令 |
| `Enter` | 执行命令 |
| `Esc` | 退出命令模式 |
| `↑↓` | 滚动输出 |

## 常用工作流

### 编辑 JSON 值（Vim 风格）
1. Dashboard: 选择 key → `Enter`
2. Normal 模式: `i` 进入 Insert
3. Insert 模式: 编辑内容
4. `Esc` 返回 Normal
5. `:w` 保存（或 `:wq` 保存并返回）
6. `:q` 返回 Dashboard

### 快速修改单词
1. Normal 模式: 移动到单词
2. `ciw` 修改单词
3. 输入新内容
4. `Esc` 返回 Normal
5. `:wq` 保存并返回

### 复制粘贴
1. Normal 模式: `v` 进入 Visual
2. `hjkl` 选择内容
3. `y` 复制
4. 移动到目标位置
5. `p` 粘贴

## 提示
- 不熟悉 Vim？使用方向键和鼠标也可以
- 按 `Esc` 总是返回 Normal 模式或退出命令模式
- 在 Normal 模式按 `:` 进入 Vim 命令模式
- 支持 `:w`（保存）`:q`（退出）`:wq`（保存并退出）`:q!`（强制退出）
- `Ctrl+s` 保存功能保留用于兼容
- 使用 `:q` 或 `:q!` 返回 Dashboard
