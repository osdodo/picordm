# 快速参考 - 按键绑定

## 全局快捷键

| 按键     | 功能     |
| -------- | -------- |
| `Ctrl+q` | 退出应用 |
| `F10`    | 打开设置 |

## Dashboard 模式

| 按键     | 功能                  |
| -------- | --------------------- |
| `↑↓`     | 选择 key              |
| `Enter`  | 打开选中的 key        |
| `Space`  | 选择/取消选择 key     |
| `Ctrl+a` | 全选/取消全选                  |
| `/`      | 搜索 keys             |
| `>`      | 进入命令模式          |
| `Ctrl+n` | 切换数据库            |
| `Ctrl+r` | 刷新 key 列表         |
| `F5`     | 刷新服务器统计信息    |
| `Ctrl+e` | 导出                  |
| `Ctrl+l` | 导入                  |
| `Ctrl+t` | 切换连接              |
| `Ctrl+b` | 断开连接              |
| `Delete` | 删除选中的 keys       |

## KeyContent 模式（Vim 风格）

### Normal 模式（默认）

| 按键                | 功能                     |
| ------------------- | ------------------------ |
| `hjkl`              | 左下上右移动             |
| `w` / `e` / `b`     | 单词导航                 |
| `0` / `$`           | 行首/行尾                |
| `gg` / `G`          | 文件开头/结尾            |
| `Ctrl+d` / `Ctrl+u` | 半页下/上                |
| `i`                 | 进入 Insert 模式         |
| `a`                 | 在光标后进入 Insert      |
| `A`                 | 在行尾进入 Insert        |
| `o` / `O`           | 新建行并进入 Insert      |
| `v`                 | 进入 Visual 模式         |
| `x`                 | 删除字符                 |
| `dd`                | 删除行                   |
| `yy`                | 复制行                   |
| `p`                 | 粘贴                     |
| `u`                 | 撤销                     |
| `Ctrl+r`            | 重做                     |
| `Ctrl+d`            | 半页下跳                 |
| `Ctrl+u`            | 半页上跳                 |
| `ciw`               | 修改单词                 |
| `:w`                | 保存到 Redis（Vim 风格） |
| `:q`                | 返回 Dashboard           |
| `:wq`               | 保存并返回               |
| `:q!`               | 强制退出不保存           |

### Insert 模式

| 按键        | 功能             |
| ----------- | ---------------- |
| 字符输入    | 正常输入         |
| `Enter`     | 换行             |
| `Backspace` | 删除前一个字符   |
| `Esc`       | 返回 Normal 模式 |

### Visual 模式

| 按键   | 功能             |
| ------ | ---------------- |
| `hjkl` | 扩展选择         |
| `y`    | 复制             |
| `d`    | 删除             |
| `Esc`  | 返回 Normal 模式 |

## 命令模式

命令模式支持两种焦点状态，可以使用 `Tab` 键在输入和浏览之间切换：

### 输入焦点（默认）

| 按键     | 功能            |
| -------- | --------------- |
| 输入命令 | 输入 Redis 命令 |
| `Enter`  | 执行命令        |
| `Tab`    | 切换到浏览输出  |
| `Esc`    | 退出命令模式    |

### 浏览焦点（查看命令输出）

| 按键                | 功能                                 |
| ------------------- | ------------------------------------ |
| `hjkl` / `↑↓←→`     | 导航输出内容                         |
| `v`                 | 进入 Visual 模式选择文本             |
| `i`                 | 进入 Insert 模式编辑（只读输出不可用） |
| `Ctrl+d` / `Ctrl+u` | 半页下/上                            |
| `gg` / `G`          | 跳到开头/结尾                        |
| `Esc`               | 退出 Visual/Insert 模式，或退出命令模式 |
| `Tab`               | 切换回输入焦点                       |

**提示**: 
- 当有命令输出时，按 `Tab` 键可以切换到浏览模式，使用 Vim 风格的按键（hjkl）浏览输出内容
- 在浏览模式下，按 `v` 可以进入 Visual 模式选择文本，按 `y` 复制
- 在 Visual 或 Insert 模式下，第一次按 `Esc` 会退出该模式回到 Normal 模式，再次按 `Esc` 才会退出命令模式
- 按 `Tab` 可以随时返回输入模式继续输入命令

## 快速连接切换

从 Dashboard 按 `Ctrl+t` 打开快速连接切换对话框：

### 导航模式（默认）

| 按键     | 功能                    |
| -------- | ----------------------- |
| `↑↓`     | 导航连接                |
| `j`/`k`  | 导航连接                |
| `1-9`    | 快速选择（前9个）        |
| `/`      | 进入搜索模式            |
| `Enter`  | 切换到选中的连接        |
| `Esc`    | 关闭对话框              |

### 搜索模式

按 `/` 进入搜索模式：

| 按键        | 功能                    |
| ----------- | ----------------------- |
| 输入文本    | 过滤连接                |
| `↑↓`        | 导航过滤结果            |
| `Backspace` | 清除搜索文本            |
| `Enter`     | 切换到选中的连接        |
| `Esc`       | 退出搜索模式            |

**提示**:
- 按 `/` 激活搜索模式后才能输入搜索
- 搜索匹配连接名称和主机地址
- 第一个匹配结果会自动选中
- 在搜索模式下按 `Esc` 返回导航模式
- 再次按 `Esc` 关闭对话框

## 设置对话框

按 `F10` 打开设置对话框：

| 按键               | 功能                        |
| ------------------ | --------------------------- |
| `↑↓` / `j`/`k`     | 导航设置项                  |
| `Tab`              | 导航设置项                  |
| `←→` / `h`/`l`     | 切换主题（深色/浅色）       |
| `Space` / `Enter`  | 切换当前设置                |
| `Esc`              | 关闭设置                    |

**提示**:
- 主题更改会立即生效
- 关闭对话框时会自动保存设置
- 深色主题支持背景透明选项

## 常用工作流

### 编辑 JSON 值（Vim 风格）

1. Dashboard: 选择 key → `Enter`
2. Normal 模式: `i` 进入 Insert
3. Insert 模式: 编辑内容
4. `Esc` 返回 Normal
5. `:w` 保存（或 `:wq` 保存并返回）
6. `:q` 返回 Dashboard

### 快速修改单词

1. Normal 模式: 移动到单词
2. `ciw` 修改单词
3. 输入新内容
4. `Esc` 返回 Normal
5. `:wq` 保存并返回

### 复制粘贴

1. Normal 模式: `v` 进入 Visual
2. `hjkl` 选择内容
3. `y` 复制
4. 移动到目标位置
5. `p` 粘贴
